# Lumen Sync User Guide

## Installation

Lumen Sync supports Windows 10 or later, macOS 12 or later, and major Linux distributions with
glibc 2.31+. Download the installer from the account dashboard after signing up.

## Account Setup

Create a Lumen account with a work or personal email address. Email verification is required
before the desktop client can sign in for the first time.

## Sync Behavior

Lumen Sync checks for local file changes every 30 seconds and uploads changes within 2 minutes
under normal network conditions. Files larger than 5 GB sync in chunks and can be paused and
resumed.

## Storage Limits

The Free plan includes 5 GB of storage. The Pro plan includes 1 TB of storage. The Business plan
includes unlimited storage with a 500 GB per-file limit.

## Sync Conflicts

When the same file changes on two devices before syncing, Lumen keeps both versions and appends
"(conflicted copy)" plus the device name to the older file's name.

## Uninstalling

Uninstalling the desktop client does not delete files already uploaded to Lumen cloud storage.
Files remain accessible from the web dashboard and any other signed-in device.
